# practica-github
El propósito de GitHub es poder guardar archivos en la nube, también sirve para trabajar en equipo y para poder ver el historial de versiones de un archivo, modificado por ti o por tu equipo.  
En este repositorio he añadido un archivo titulado "hola_mundo.py", al que le he ido modificando el código dos veces para poder practicar, para poder ver el historial de versiones y para así lograr aprender más sobre Github.
